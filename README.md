# preview-image-cli

CLI tool to preview images directly in the terminal using [Spectre.Console](https://spectreconsole.net/)'s canvas image rendering.

## Usage

```
preview-image <path> [--max-width=<width>]
```

### Example

```bash
preview-image photo.png
preview-image photo.png --max-width=80
```
